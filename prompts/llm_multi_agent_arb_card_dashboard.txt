### Card zones (required)

- Sport badge (derive from `sport_key`: `baseball_mlb` → MLB)

- Humanized `market_label` (e.g. `totals` → Totals, `player_doubles` → Total Doubles, `h2h` → Moneyline)
- `commence_time` in user local TZ (e.g. Tue 6/9 @ 10:05pm EDT)

**2. Split legs (2-column grid for 2-way arb)**
Per leg (`legs[]` from API):
- Book logo placeholder (initials circle) + `source` display name (DraftKings, FanDuel, …)
- Bold `outcome` + `line` if present (e.g. "Under 3.5 doubles", "Over 3.5")
- **American odds** large (convert from decimal `price` for display only)
- Market average odds small grey under price (from `market_avg_american` or compute from `quote_matrix`)
- Editable stake `$` input — default from bankroll formula
- Payout in green (stake × decimal price)
- "Bet First" pill on leg with **lower** `stake_weight` (higher decimal / underdog side)

**3. Place Both**
- Tall button right column: "Place Both" + lightning icon
- Click → `alert('Manual placement — link to books below')` OR open book URLs (see BOOK_URLS map)

**4. Comparison table (bottom of card)**
- Rows: each outcome side (Under 3.5 / Over 3.5)
- Columns: Market label | Market Avg | one column per book in `quote_matrix`
- Highlight **best** decimal price per row in green
- Grey out non-best

### Top of page (above cards)
- Bankroll slider `$100` – `$50,000` (default `$1000`) — `localStorage`
- Stats row: total opps, avg ROI, best ROI (from `/api/status` `stats`)
- Day tabs: Today / Tomorrow / Sources (keep existing tab behavior)
- Refresh run button (keep `#btn-refresh`)

### Empty state
When `opportunities.length === 0`: show scanned events list OR message:
"No arbitrage opportunities right now. Lines are still scanned — try Refresh run or lower HARVESTER_MIN_ARB_YIELD_PCT."

### Odds helpers (implement in JS + optional Python)

```javascript
// decimal → american (display only)
function decimalToAmerican(d) {
  if (d >= 2) return `+${Math.round((d - 1) * 100)}`;
  return `${Math.round(-100 / (d - 1))}`;
}

// stakes for bankroll B
function allocateStakes(legs, B) {
  const wSum = legs.reduce((s, l) => s + l.stake_weight, 0);
  return legs.map(l => ({
    ...l,
    stake: B * (l.stake_weight / wSum),
    payout: B * (l.stake_weight / wSum) * l.price,
  }));
}
// profit = payout - B (equal payouts for valid arb)
```
