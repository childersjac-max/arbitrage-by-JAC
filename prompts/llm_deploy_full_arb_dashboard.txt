## TARGET STATE (definition of done)

### A. All books considered

For every ingest run, include quotes from **every US regulated book** returned by The Odds API in region `us`:

- `draftkings`, `fanduel`, `betmgm`, `williamhill_us`/`caesars`, `fanatics`, `thescore`/`espnbet`

Do **not** drop books in `filter_records_to_target_sources()` if they map to `TARGET_SOURCES`. Log which books returned zero quotes.

Direct-only sources (`bet365`, `kalshi`, `polymarket`, exchanges) stay in `target_sources.py` as stubs until official API keys exist — show "Not connected" in dashboard, do not fake data.

### B. All line types considered

Every run must fetch and score arbitrage across:

| Type | Odds API keys |
|------|---------------|
| Moneyline | `h2h` |
| Spreads | `spreads` |
| Alt spreads | `alternate_spreads` |
| Totals | `totals` |
| Alt totals | `alternate_totals` |
| Player props | `player_points`, `player_rebounds`, `player_assists`, `player_threes`, (+ sport-specific) |
| Alt player props | `player_points_alternate`, `player_rebounds_alternate`, `player_assists_alternate` |

**Bulk endpoint** (`/odds`) → featured h2h, spreads, totals only.  
**Event endpoint** (`/events/{eventId}/odds`) → alternates + props (implement if missing).

### C. Arb engine covers every line type

Refactor `harvester/engine.py` so scoring is **per market group**, not one h2h pass on a merged blob:

- **h2h:** two outcomes, best price per side across all books
- **spreads / alt spreads:** match same team + same point (e.g. LAL -3.5); arb on both sides
- **totals / alt totals:** match same point (O/U 220.5); arb on over vs under
- **player props:** match `player_name` + stat type + point; never arb mismatched lines

Each opportunity in the dashboard must show: `event`, `market_type`, `line`/`point`, `yield_pct`, `legs[]` with book + outcome + price.

### D. All configured leagues

Default sports loop (env-driven):

```
basketball_nba, americanfootball_nfl, baseball_mlb, icehockey_nhl
```

Orchestrator merges all sports into one snapshot (or per-sport files + dashboard aggregates).

### E. Deployed dashboard with accessible URL

User must be able to open a URL and see live results:
