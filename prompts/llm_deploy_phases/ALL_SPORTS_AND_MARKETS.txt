## ALL BET TYPES — featured (bulk `/v4/sports/{sport}/odds`)

Always request for **every sport** (1 credit × market × sport):

| Type | API key | Arb matching |
|------|---------|--------------|
| Moneyline / 1X2 / H2H | `h2h` | best price per outcome |
| Point spread | `spreads` | same team + same point |
| Totals O/U | `totals` | same point, over vs under |
| Outrights / futures | `outrights` | same selection (futures arbs rare) |

Bulk markets string: `h2h,spreads,totals,outrights`

## ALL BET TYPES — event depth (`/events/{eventId}/odds`)

Request per event (1 credit × market × event). Merge all into snapshot.

### Universal alternates
- `alternate_spreads`
- `alternate_totals`
- `alternate_team_totals`

### Basketball (NBA/NCAAB/WNBA)
- `player_points`, `player_rebounds`, `player_assists`, `player_threes`, `player_blocks`, `player_steals`, `player_turnovers`, `player_points_rebounds_assists`
- `player_points_alternate`, `player_rebounds_alternate`, `player_assists_alternate`, `player_threes_alternate`

### Football (NFL/NCAAF)
- `player_pass_tds`, `player_pass_yds`, `player_rush_yds`, `player_receptions`, `player_reception_yds`, `player_anytime_td`
- `*_alternate` variants per Odds API docs

### Baseball (MLB)
- `batter_home_runs`, `batter_hits`, `batter_rbis`, `pitcher_strikeouts`, `pitcher_hits_allowed`
- alternates per docs

### Hockey (NHL)
- `player_points`, `player_goals`, `player_assists`, `player_shots_on_goal`
- alternates per docs

### Soccer
- `btts`, `draw_no_bet`, `alternate_spreads`, `alternate_totals`, `player_goal_scorer_anytime`
- many league-specific markets — discover from API response per event

### MMA / Boxing
- `h2h` primary; method-of-victory props on event endpoint when available

Reference: https://the-odds-api.com/sports-odds-data/betting-markets.html

- Bulk: `active_sports × 4 markets` credits
